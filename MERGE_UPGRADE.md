# AI Reel Generator v1.8 — Brand Engagement Engine

This build merges the secure Vercel/audio workflow of the v1.3.x Engagement Engine with the background-control direction of v1.7, then applies the new brand rules.

## Core rules
- No gradient backgrounds anywhere in the reel scene background engine.
- Clean aligned typography; no scattered/random word placement.
- 10 selectable brand themes.
- Each brand theme locks one hook font + one body font across the reel.
- 20 animation families rotate with anti-repetition logic.
- Default visual cadence is alternate: visual → text-only → visual → text-only.
- Visual text is semantic/diagram copy, never the full spoken subtitle sentence.
- Minimal background by default, with optional short solid-color hook flashes.
- Secure Vercel login, Private Blob, signed temporary media links, audio preview fix, and cloud rendering remain included.

## Recommended defaults
- Brand Theme: Signal Red
- Typography Variety: Maximum Variety
- Visual Rhythm: Alternate Scenes
- Background Behaviour: Minimal + Hook Flash
- Background Motion: Subtle Shapes

Use `DEPLOY_TO_VERCEL.bat` to replace the current production deployment on the existing main Vercel project.
