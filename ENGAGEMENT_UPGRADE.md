# Engagement Upgrade Notes

The v1.3.3 engine specifically addresses four problems: repeated typography motion, normal-looking hook fonts, consecutive visuals, and visuals duplicating the same sentence that is already on screen.

The engine now assigns each scene an animation family, typography layout, hero font, hero treatment, background palette and background treatment. It also enforces cooldowns between adjacent scenes.

Visual cadence defaults to alternating scenes. Visual bindings are semantic and illustrative rather than a copy of the scene narration.
