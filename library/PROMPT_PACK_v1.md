# Master Asset Library — Prompt Pack v1 (≈207 images, generate once)

**Purpose:** make the whole reusable library **one time**, in bulk. After that, every video is built from:
1. This library
2. Charts, screenshots and text cards that I make myself
3. A small number of one-off gags, which I generate myself through the Gemini API once the key is set up

## How to generate

1. **Reference image:** attach `library/style_reference/style_sheet.jpg` (the approved sheet) as an ingredient for **every** prompt in sections A, B and C. For D, E and F it is optional but still helps keep the line style matching.
2. **Paste the style line** after every prompt.
   - Sections A–E (**STYLE**): *Simple hand-drawn doodle cartoon, thick black marker outlines with slightly wobbly lines, flat colours, minimal detail, no shading, no gradients, pure white background, centred, full body, lots of empty space around the subject, no text.*
   - Section F (backgrounds) uses its own line, given there.
3. **Choosing:** make 2 options per prompt and keep the best one. **Don't rename the files.** Each prompt starts with unique words, and Flow names the file after those words, so I can match every file automatically.
4. **Work in batches of 24 images.** Finish one batch, zip it, send it to me, then start the next. You don't need to wait for my reply between batches.

| Batch | Prompts | Images |
|---|---|---|
| 1 | A01 – A24 | 24 |
| 2 | A25 – A48 | 24 |
| 3 | A49 – A50, B01 – B12, C01 – C10 | 24 |
| 4 | C11 – C28, D01 – D06 | 24 |
| 5 | D07 – D30 | 24 |
| 6 | E01 – E24 | 24 |
| 7 | E25 – E48 | 24 |
| 8 | E49 – E55, F01 – F08 | 15 |
| 9 | G01 – G24 | 24 |

5. **Order:** go from batch 1 to batch 8. The sample video needs only batches 1, 3 and parts of 5–7, so the sample can be finished early.

Character shorthand used below:
- **NARRATOR** = *the same stick-figure man from the reference image (round peach head, messy brown hair, round glasses, orange scarf)*
- **PENNY** = *the same pink piggy bank character Penny from the reference image*

Write the full description in place of the word each time. Flow does not know the shorthand.

### What still happens per video (no work for you)
- **Charts, news screenshots, headline cards and text:** I make these.
- **Combinations:** a narrator "empty hand" pose plus any prop. I join them in the edit.
- **One-off gags** (like "a country map wearing sunglasses"):
  - With the Gemini API key set up, I generate them myself.
  - Without it, I build the gag from library pieces, or skip it.
